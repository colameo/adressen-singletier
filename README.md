# AdressenSingletier

A single-tier application: a web site of plain HTML and Alpine.js, with no backend and no database. The data lives in the browser
(`localStorage`); **Save data** and **Load data** in the menu bar write and read it as a JSON file. Generated by Pisa from the model
(`spec/base/*.dml`) and the architecture (`spec/base/*.adl`, a frontend container with `storage json`).

```
npm start          # the site on http://localhost:8080
npm test           # the architecture test: nothing in public/ calls a server
npm run test:ui    # a browser test per page (npx playwright install chromium, the first time)
npm run package    # the site as a ZIP file: dist/adressen-singletier.zip
```

The libraries (Alpine.js, Bootstrap, validator.js, @faker-js/faker) are loaded from a CDN, with the versions of
`.pisa/architecture.plan.json`; the site needs the network for them.
